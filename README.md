# Heart Rate Track Project

This is the University of Arizona ECE513 course project repo. Introduction can be found in the home page.

## Pre-requisite

CLONE THIS REPO AS THE ROOT FOLDER OF THE PROJECT.

Make sure you installed nvm and express.

## Setup & Launch

Enter this folder.

```
cd ECE513-Project
cd project
```

Install Node.js v18.

```
nvm install 18
```

Set Node.js v18 as the Default.

```
nvm use 18
nvm alias default 18
```

Install all packages.

```
npm install
```

Start the session.

```
npm start
```

The application runs on <http://54.177.57.86:3000/>.
